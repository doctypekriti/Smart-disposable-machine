# Smart Disposal Machine

An IoT-enabled smart waste management system designed to improve hygiene and efficiency in hostels, canteens, and public spaces.

## Key Features

- Real-time waste level monitoring using ultrasonic sensors
- Automated waste sealing and packaging mechanism
- Automatic garbage bag replacement system
- Conveyor-based waste transfer to storage compartment
- ESP32-based wireless monitoring and automation
- Improved hygiene through reduced manual handling

## Technologies Used

- ESP32 Microcontroller
- Ultrasonic Sensors
- DC Motors
- Conveyor Belt Mechanism
- IoT Communication

## Applications

- Hostels
- Canteens
- Educational Institutions
- Public Spaces
